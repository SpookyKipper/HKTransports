# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest 0.1.x | :white_check_mark: |

## Reporting a Vulnerability

There are several ways to report a vulnerability for HKTransports:
1. Via [Spooky Services Advisories Portal](https://advisories.spookysrv.com/request/spooky-services%2Fspookykipper%2Fhktransports) (Recommended)
2. Via [GitHub Private Vulnerability Reporting](https://github.com/SpookyKipper/HKTransports/security/advisories/new)
3. Email security@spooky.hk OR security@spookysrv.com with all the details
